# Superseded drafts

Kept for the record, not for submission. Nothing in `scripts/` reads these files.

| File | Replaced by | Why |
|---|---|---|
| `main.tex` | `paper/latex/main.tex` | IEEE conference format, written before the venue decision. The paper goes to a journal (*Biomedical Signal Processing and Control*), which wants `elsarticle`. The current file is generated by `scripts/build_latex.py`, not edited by hand. |
| `01_introduction.md` | `paper/sections/02_introduction.md` | An early Introduction written before the cross-validation results existed. Its claims come from the single-split run and several are no longer true. |
| `references.md` | `paper/references.bib` | A reading list with `[verify]` placeholders. Every entry has since been checked against Crossref by `scripts/verify_references.py`; the `.bib` is the one that is correct. |

If you are looking for the manuscript, it is `paper/paper_full.md` to read and
`paper/sections/*.md` to edit.
